# Quick Start Guide  
  
Get up and running in 2 minutes.  
  
## Install  
  
```bash  
pip install plan-auditor  
```  
  
## Your first verified task  
  
1. Open your project folder  
2. Tell your AI assistant: "Use plan-auditor for this task"  
3. Describe what you want built  
4. Watch as every step gets verified with real evidence  
  
## What you will see  
  
Instead of "done, trust me", you get:  
  
- Exact commands that were run  
- Their actual output  
- File hashes proving nothing was tampered with  
- A sealed audit trail you can re-verify anytime
